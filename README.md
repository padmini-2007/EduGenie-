# EduGenie — AI/ML/GenAI Track Project Submission

## Project
**EduGenie – AI-Powered Educational Assistant**

EduGenie integrates a React frontend, Node.js/Express backend, MongoDB, LangChain, Google Gemini, and Python/FastAPI services to provide personalized academic assistance.
